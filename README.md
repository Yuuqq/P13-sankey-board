## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅲ 实操篇 · 第10章 数据新闻可视化实践**（教材 Tier 1 实验工具）。教材命名："桑基图快捷面板"。

**学习目标**：理解桑基图适合表达的"流量分流"关系，能把资金流向数据整理为"来源 去向 金额"结构并生成图表，学会用数据—墨水比原则精简可视化作品。

**核心术语**：桑基图（Sankey Diagram）、数据—墨水比（Data-ink Ratio）、节点与流向（Node & Flow）

**适合对象**：新闻传播专业学生、数据新闻初学者、调查记者

**课前准备**：课前领取教师提供的资金流向清单（或自选一份预算、捐款等流量型数据，8-10 条记录即可）；本工具打开即用、离线可用。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师在"关系输入"框逐行输入一组"某基金会→壳公司→供应商"示例（每行"来源 去向 金额"），点击"生成桑基图"，讲解节点、连线宽度与金额的对应关系
2. **上手实操**（20 分钟）：学生按教材实验步骤完成：①把资金流向清单整理为每行"来源 去向 金额"的文本；②粘贴并生成桑基图，按报错提示修正格式；③对照原始金额核对连线宽度与分流合计是否守恒；④删去可有可无的中间节点与装饰，讨论每次修改如何提升数据—墨水比；⑤分别点击"导出 SVG"与"导出 PNG"，比较两种格式在交稿与网页嵌入中的用途
3. **小组讨论**（8 分钟）：与柱状图、表格相比，桑基图呈现资金链时牺牲了什么精度？什么样的数据用桑基图反而会误导读者？
4. **总结**（4 分钟）：图形选择服务于关系表达，删到只剩数据本身才是好图

**课后作业**：用一份真实（或教师提供）的预算、捐款数据制作桑基图，导出 SVG 并撰写 150 字图注（含数据来源、单位与一句核心发现）

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。
